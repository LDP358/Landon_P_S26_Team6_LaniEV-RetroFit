SOLAR TRACKER — MATLAB DIGITAL TWIN v2.2
48 x 68 inch panel | N/W edge-mounted virtual actuators | S/E elbow supports
========================================================================

INSTALL / RUN
1. Unzip all files into ONE folder.
2. In MATLAB, make that folder the Current Folder.
3. Run:
     clear x_sensor_tracker_demo x_sensor_core tracker_config
     x_sensor_tracker_demo
4. To run built-in numerical checks, enter:
     verify_x_sensor_tracker
5. Use EXPORT CSV in the GUI to save sensor errors, position, force,
   illustrative current, and cumulative estimated electrical energy.

- Dimensions: East-West width = 48 in; North-South length = 68 in.
- Area = 3264 square inches = 22.667 square feet = 2.1058 square meters.
- Panel + upper moving frame weight = 55 lbf (unchanged assumption).
- Moving assembly CG = 6 in above center ball joint at level.
- Lower frame at z=0 in; upper frame at z=12 in when level.
- Ball joint center at (x,y,z) = (0,0,6) in.
- Maximum independent north/south pitch and east/west roll: +/-8 deg.
- Keep panel corner at least 50 mm above lower-frame plane.
- Upper mounts measured relative to ball-joint at local z=+6 in.

CLEARANCE / LINKAGES
- Idealized smallest panel corner height above z=0: about 3.858 in
  throughout simultaneous +/-8 degree limits (without brackets/beams).
- S/E articulated elbows remain two equal links of 10 inches EACH;
  the model tests whether the hinges can reach, not their actual loads.
- This is not detailed CAD collision checking. Missing: wind loading,
  actuator body clearance, yaw constraint, elbow bearing orientations,
  panel/frame stiffness, friction, backdrive/holding stability and
  mechanical end stops. Do not claim the proposed linkage is validated.

FORCE MODEL — GRAVITY ONLY
For each pose R and center-of-mass offset r_CG:
   tau_g = cross(R * r_CG, [0;0;-W])
Each unit axial force at an upper pivot causes moment
   tau_i = cross(R * upperPivot_i, axis_i)
where axis_i points from fixed lower pin toward upper pin.
The two actuators are solved together to balance x/y components of
   tau_g + F_N*tau_N + F_W*tau_W = 0
The yaw residual is reported separately. Calculations exclude all
friction, dynamic acceleration, wind, elbows' reactions, active hold.
Gravity-only force magnitude at (pitch,roll)=(+8,+8) deg:
   NORTH about 1.396 lbf; WEST about 1.968 lbf.
Values change across the tilt range; signs indicate axial direction.
The 55-lb weight and CG position are still unverified design estimates.

CURRENT MODEL — UNVERIFIED EXAMPLE ONLY
No real actuator with this length envelope has been selected. Therefore
actual currents CANNOT be identified from this force calculation alone.
Hypothetical settings in tracker_config.m:
   motor voltage: 12 V; no-load ON-state current: 1.0 A each
   overall drive efficiency: 35%; actuator speed: 0.30 in/s
   assumed extra startup current: 1.5 A for 0.08 s
   assumed DC-DC converter efficiency: 90%.
Steady example: I = 1 A + abs(force_N * speed_mps)/(0.35 * 12 V).
The GUI shows step-averaged current and illustrative instantaneous peaks.
A stopped, unpowered motor draws zero in the model, but actual holding
mechanics/backdriving are NOT assessed. No purchase, fuse, cable or
thermal rating may be derived from these fictional current parameters.

SENSOR MODEL / ARDUINO
- Four simulated light values: N,E,S,W, with diagonal X-wall shadows.
- Sensor wall orientation uses the NEW 48:68 panel aspect ratio.
- Controller sample interval: 0.20 seconds; normalized error deadband:
  0.025; proportional tilt request gain: 2 deg per unit error.
- Simulated mean low-light threshold: 100 (not calibrated ADC counts).
- Tinkercad/Arduino analogRead pins, low-light rule, and motor PWM
  DO NOT depend directly on panel physical dimensions. Arduino code
  must be revised only if physical geometry, feedback and limits
  are actually implemented in that controller.
